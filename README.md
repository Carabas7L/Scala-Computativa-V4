## Parcours de lecture

Lire le fichier comme une spécification historique et ses paramètres comme des hypothèses à examiner. « Scala V4 » et « Lexique V4.2 » désignent des objets différents ; le lexique V4.2 est la référence lexicale pour les nouveaux usages.

## Limites

Les exports, tests, tableaux de bord et chemins `AIA7L_DataCentral` cités dans le document ne sont pas présents dans ce dépôt. Aucun moteur d’exécution ni capteur de consommation n’y est fourni. Les coefficients énergétiques et les seuils déclarés ne constituent pas des mesures vérifiées. Le champ historique `meta.repo` renvoie à V3.0 ; il ne change pas l’identité de ce dépôt V4.
